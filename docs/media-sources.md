## الفيديوهات المرفقة — 2026-09-14

- `bg.mp4`: ملف قدّمه المستخدم داخل جذر المشروع؛ استُخدم كخلفية فيديو للشريحة الافتتاحية في الرئيسية.
- `bg2.mp4`: الملف الثاني الموجود فعلياً داخل المشروع؛ ذكر المستخدم اسم `bg1.mp4`، وأُبلغ بأن الموجود هو `bg2.mp4`. استُخدم في الشريحة الثانية، دون إعادة تسمية الأصل.
- الملفان الأصليان H.264 بدقة 3840×2160، مدة كل منهما 10.01 ثانية، ولا يحتويان على مسار صوتي. هما مشاهد جوية لسفن حاويات وموانئ، مع كتابة اسم الشركة المدمجة في المقطع. لا يُعكس الفيديو أو شعار الشركة.
- النسخ المنشورة داخل `public/assets/video/` بدقتي 1920×1080 و1280×720 بصيغة MP4/H.264، مهيأة لبدء التنزيل المتدرج. حجم نسخة الحاسوب يقارب 1.5 ميغابايت، والهاتف 0.8 ميغابايت لكل مقطع. بقي الأصلان دون تعديل.
- الصور البديلة `bg-poster-*` و`bg2-poster-*` إطارات مستخرجة من المقطعين نفسيهما، بحجمي 1600 و640 بكسل، ولا تحتوي على عناصر مولّدة إضافية.
- لا تثبت اللقطات ملكية الشركة للموانئ أو السفن الظاهرة. تُعرَض مع عبارة «مشاهد توضيحية»؛ وعلى المالك تأكيد ترخيص استخدام الملفين قبل النشر العام.

- الإنجليزية تستخدم خطوط النظام Helvetica Neue / Arial؛ لا يُطلب تحميل الخط العربي مسبقاً لصفحات الإنجليزية.
