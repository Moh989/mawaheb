# إصلاح الاتصال بقاعدة البيانات المحلية

التاريخ: 2026-09-12.

## السبب المؤكد

كان الموقع يصل إلى MySQL الخاص بالمشروع على `127.0.0.1:3307`، لكن الإعداد القديم استخدم `root` بلا كلمة مرور. رفض MySQL الاتصال عبر TCP والمقبس المحلي بالخطأ 1045. لم يتحدد سبب تغير قبول بيانات حساب root؛ لم تُغيّر كلمة مروره أثناء الإصلاح.

## ما نُفذ بعد موافقة المالك

- إيقاف قاعدة المشروع بأمان ونسخ مجلد البيانات وملف `.env` السابق إلى `storage/backups/mysql-repair-20260912-FY7ELw/database-before-repair.tar.gz`. اختُبرت سلامة الأرشيف؛ أذوناته `600` ومجلده خاص بالمستخدم.
- إنشاء حساب محلي جديد للموقع بكلمة مرور عشوائية، بصلاحيات `SELECT, INSERT, UPDATE, DELETE` على `almawaheb` فقط. لم تُضف صلاحيات عامة أو صلاحية إنشاء مستخدمين.
- استخدام ملف تهيئة مؤقت لعملية إنشاء الحساب فقط، دون تعطيل المصادقة أو تغيير حساب root أو جداول المحتوى. أزيل خيار التهيئة من التشغيل المعتاد وحُذفت ملفات الإصلاح المؤقتة المحتوية على كلمة المرور.
- تحديث `DB_USER` و`DB_PASS` في `.env` الخاص بالمشروع، والإبقاء على بيانات SMTP وبقية الإعدادات كما هي.
- تصحيح زر التشغيل ليختبر تسجيل الدخول باستعلام `SELECT 1` بدلاً من `mysqladmin ping` الذي لا يضمن نجاح المصادقة؛ ودعم الحساب المخصص عند تشغيل مجلد البيانات الموجود.
- إبقاء صلاحيات الحساب محدودة؛ زر الإيقاف يرسل طلب توقف آمن إلى عملية MySQL المحلية المتحقق من مسارها عند عدم امتلاك صلاحية `SHUTDOWN`، وينتظر خروجها قبل إعلان الاكتمال.

## التحقق الفعلي

- اتصال PDO ناجح بالحساب المخصص بعد إنشاء الحساب وبعد إعادة تشغيل عادية دون ملف التهيئة.
- التحقق من صلاحيات الكتابة باستعلامات لا تطابق أي صف داخل معاملة تم التراجع عنها؛ لم يُضَف طلب تواصل أو يُعدَّل محتوى للاختبار.
- رفض وصول الحساب إلى جدول مستخدمي MySQL، والتحقق من أن المنح مقيدة بقاعدة الموقع.
- نجاح دورة إيقاف وتشغيل كاملة بالزرين، ثم إعادة الضغط على زر التشغيل والموقع يعمل.
- تطابق بصمات بيانات الجداول التسعة قبل دورة إعادة التشغيل وبعدها: 4 صفحات، 12 ترجمة صفحة، 5 خدمات، 15 ترجمة خدمة، 21 إعداداً، حساب إداري واحد، 6 طلبات تواصل، وسجلان لتقييد المحاولات. لم توجد سجلات في جدول الوسائط؛ لم تتغير ملفات الصور.
- استجابة 200 للصفحات الأربع باللغات الثلاث وصفحة تسجيل الدخول وخريطة الموقع، دون رسالة SQLSTATE أو خطأ PHP. مسار الإدارة المحمي يعيد الزائر غير المسجل إلى تسجيل الدخول؛ وصفحة غير موجودة تعيد 404.
- نجاح فحص صياغة ملفي التشغيل والإيقاف.

لم تتغير بيانات حساب لوحة الإدارة، ولم يُنفذ تسجيل دخول بكلمة مرور المستخدم أو نشر محتوى أو اختبار SMTP. هذه إصلاحات للبيئة المحلية؛ ليست تغييراً لإعدادات استضافة خارجية.
