# نواقص المحتوى

تمت مراجعة صفحات الملف التعريفي الـ12 والشعار المرفق. المعلومات التالية لم ترد بصورة مؤكدة، لذلك لا تظهر للزائر وتبقى حقولها فارغة في لوحة الإدارة:

- ساعات وأيام العمل.
- روابط حسابات Facebook وInstagram وLinkedIn أو أي شبكة اجتماعية أخرى.
- رابط خريطة أو إحداثيات دقيقة قابلة للتحقق.
- ترجمة كوردية معتمدة من الشركة. أُعدّت نسخة سورانية كاملة للمراجعة وموسومة داخل الإدارة «بحاجة إلى مراجعة لغوية».
- أسماء العملاء أو الشركاء أو أي شعارات لهم.
- شهادات أو اعتمادات عامة للشركة. وردت شهادة IFA ضمن وصف فاحصي المشروع المذكور في الملف فقط، لذلك لم تُقدّم كشهادة مؤسسية عامة في الموقع.
- ضمانات زمنية لإنجاز المعاملات أو أسعار ورسوم ثابتة.

لم يُنشأ نظام تتبع شحنات للزوار أو حاسبة رسوم أو تكامل حكومي. «متابعة الشحنات» معروضة كخدمة موثقة فقط، وليست ميزة تتبع رقمية.
